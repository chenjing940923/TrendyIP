朝陽科技大學視覺傳達設計系「設計人格 IP 角色創作競賽」官方網站
主題：「潮派 IP 由你來 P」
==========================================================================

本專案為朝陽科技大學視覺傳達設計系所主辦之「設計人格 ｜ IP 角色創作競賽」官方宣傳與模擬報名網站。
網頁排版設計仿照「獎金獵人 (Bhuntr)」競賽詳情頁面，以深色霓虹潮流風格 (Dark Cyber-Street Style) 呈現，
專為設計科系學生打造一個具視覺張力與豐富互動的前端網頁。

--------------------------------------------------------------------------
一、 專案目錄與檔案結構
--------------------------------------------------------------------------
├─ index.html       - 網站主頁面 (HTML5 語意化標籤結構)
├─ styles.css       - 全域樣式表 (客製化毛玻璃效果、3D翻轉卡片、響應式排版)
├─ app.js           - 網頁互動與功能邏輯 (倒數計時、滾動監聽、試算器、投票、表單驗證)
├─ assets/          - 專案靜態資源與圖片 (如 banner 與角色概念圖)
├─ 參考文件/         - 網站建置計畫書及競賽主企劃書等背景文檔
└─ README.txt       - 本說明文件

--------------------------------------------------------------------------
二、 核心功能與特色
--------------------------------------------------------------------------
1. 潮流霓虹視覺設計
   - 以深紫色為背景底色，搭配霓虹黃、霓虹粉、霓虹青的漸層發光與毛玻璃效果 (Glassmorphism)。
   - 採用 Fit-size 響應式字體與現代幾何字體 Outfit 與 Noto Sans TC。

2. 雙欄響應式佈局 (RWD)
   - 電腦端採用 70% 左側內容區與 30% 右側懸浮側邊欄 (Sticky Sidebar) 佈局。
   - 行動端自動降為單欄，且底部常駐「截止時間倒數與報名」快捷條，方便快速報名。

3. 橫向滾動導覽與 ScrollSpy 監聽
   - 頂部 Tab 導覽列在滾動時，會根據瀏覽位置自動高亮點亮對應的單元，並微調偏移量以避免被 Header 遮擋。

4. 五大設計人格 3D 翻轉卡片
   - 包含「格哥」、「彩洸」、「像點」、「尺原」、「稿夜」五大設計人格方向。
   - 點擊卡片會觸發 3D 翻轉動畫，展示該人格的個性設定、視覺元素與風格印象。

5. 大賽截止倒數計時器
   - 右側側邊欄與行動端底部快捷條會動態計算至 2027年10月30日 23:59:59 截止時間之倒數。

6. 資格與獎金試算器
   - 參賽者可輸入隊伍人數與預估投稿組數，系統將即時驗證是否符合簡章規範 (2-3人組隊，每隊最多投5組)，並估算最大首獎金額。

7. 人氣設計人格打氣投票
   - 使用者可以為最符合自己的設計人格投票，系統會與瀏覽器的 localStorage 結合，限制單人僅能投票一次，並即時以百分比和進度條顯示當前人氣。

8. 模擬線上報名與防呆表單
   - 包含完整的表單驗證邏輯（如：必填欄位、Email格式、台灣手機格式、原創聲明勾選）。
   - 設計拖曳上傳區，方便上傳 .ai 原始檔與 .jpg/.png 圖檔。

9. 社群分享小工具
   - 支援快速模擬分享至 Facebook、Line 以及一鍵複製網站連結。

--------------------------------------------------------------------------
三、 啟動與執行方式
--------------------------------------------------------------------------
由於本專案採用純前端技術 (Vanilla HTML / CSS / JavaScript) 開發，無任何第三方框架依賴，您可以透過以下兩種方式執行本專案：

方法一：直接開啟
- 直接在瀏覽器中按兩下「index.html」即可啟動並瀏覽本網站。

方法二：使用本地伺服器 (推薦)
為了能讓部分瀏覽器元件正常載入，推薦使用本地開發伺服器開啟。
- 若您使用 VS Code，可安裝擴充功能「Live Server」，並在「index.html」按右鍵選擇「Open with Live Server」。
- 或於專案根目錄下使用命令列執行：
  * 使用 Python: python -m http.server 8000 (然後在瀏覽器輸入 http://localhost:8000)
  * 使用 Node.js: npx http-server (然後在瀏覽器輸入 http://localhost:8080)
