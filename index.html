大賽簡介

前言

「設計人格｜IP 角色創作競賽」以推廣朝陽視傳系為核心，透過舉辦視傳系 IP 角色設計競賽，邀請高中職學生與大專院校生共同參與。活動以線上投稿平台為主要參賽管道，結合線下校內展覽、人氣打卡區與頒獎典禮，打造兼具創意競賽與品牌推廣之整合行銷活動，形成完整的品牌推廣機制。藉由參賽者的創作品，發掘能代表朝陽視傳系精神的角色形象，進一步建立系所專屬 IP 角色，作為未來宣傳與文創延伸的重要核心資產。

動機與目的

隨著設計教育的普及與文創產業的興盛，角色 IP 已成為品牌形象與塑造傳遞的重要媒介。朝陽視傳系長期致力於培養具創意與實踐力的設計人才，目前尚未建立具代表性的角色形象，使得宣傳多停留在單次視覺作品，缺乏延續性與記憶點。

因此，本企劃透過競賽形式推動校系形象，吸引目標族群參與創作，深入了解視傳系的專業特色與創意精神理念，同時藉由活動曝光與互動，提升系所知名度與招生吸引力，並為未來的文創商品開發奠定基礎。

現有問題與解決方案

目前朝陽視傳系在對外推廣上仍缺乏具高度辨識度的代表性 IP 角色，使整體品牌形象較為分散，難以形成一致且鮮明的視覺記憶。現行招生與宣傳方式多以靜態資訊呈現為主，互動性與參與感不足，較難有效吸引學生族群注意關注。因此，透過舉辦「設計人格｜IP 角色創作競賽」，不僅能補足品牌形象的缺口，也能以創意競賽的形式強化與潛在學生的連結，達成教育推廣與品牌塑造的目標。

五大設計人格方向

本次「設計人格」主題以將角色外型設計元素人格化為核心概念，透過 IP 角色設計創造能代表朝陽視傳系特色與設計精神的原創角色。參賽者可自以下五種設計人格設計方向延伸發想，融合設計元素與角色個性設定，將視覺設計中常見的元素、工具與創作概念轉化為具有個性與故事性的角色形象：

參賽辦法

參賽資格

  • 以全台高中職設計相關科系學生為主要參與對象。
  • 全國大專院校生皆可參加，對角色設計、插畫創作與 IP 角色有興趣者皆可報名。

報名方式

  • 本次競賽採線上報名與作品上傳方式進行，參賽者須於活動截止前完成資料填寫。
  • 以兩至三人為一組之團隊形式參賽，每組須共同完成五隻角色設計投稿，作為完整系列投稿，每組參賽團隊最多可投稿 5 組作品。
  • 投稿內容應包含：角色設計作品、角色名稱、角色設定以及創作理念說明，需依據五種角色設計人格方向進行發想。

作品規格

排版尺寸 A3尺寸（297 x 420 mm），五隻角色設計合成一張。
檔案格式 需提供 Adobe Illustrator (.ai) 原始檔，並附上 JPG 或 PNG 檔。
解析度 影像解析度須達 300dpi。
原創限制 競賽作品須為原創設計，禁止使用 AI 生成圖像工具進行角色創作。若經查證抄襲、AI生成或侵權，將取消參賽資格。
