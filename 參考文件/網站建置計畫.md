# 朝陽科大視傳系「設計人格 IP 角色創作競賽」網站建置計畫書

本計畫書旨在為朝陽科技大學視覺傳達設計系主辦之「設計人格 ｜ IP 角色創作競賽」（主題：「潮派 IP 由你來 P」）規劃並建置一個極具設計感、潮流感且互動性佳的官方競賽網站。網站排版設計仿照「獎金獵人 (Bhuntr)」競賽詳情頁面，以符合設計科系學生熟悉且資訊清晰的閱讀習慣。

---

## 一、 視覺風格與設計定位

本專案將網站視覺風格定調為**「街頭潮流與數位科技融合的深色霓虹風 (Dark Cyber-Street Style)」**，以呼應朝陽視傳系「潮派 IP」的競賽主視覺：

1.  **色彩計畫**：
    *   **主背景色**：午夜深紫黑 (`#08040d`)、深紫色面板 (`#12091c`)。
    *   **霓虹黃 (`#f3e03b`)**：用於首獎金額、主要行動按鈕及重要狀態，創造黃金般的高亮感。
    *   **霓虹粉 (`#ff2e93`)**：用於狀態標籤（如「徵件中」）、錯誤提示及 Hover 強調。
    *   **霓虹青 (`#00f0ff`)**：用於科技感元素、輸入框 Focus 外框及成功狀態顯示。
    *   **霓虹紫 (`#9d4edd`)**：用於邊框漸層發光與毛玻璃面板。
2.  **毛玻璃效果 (Glassmorphism)**：
    *   各內容區塊採用背景半透明 (`rgba(20, 10, 30, 0.65)`) 與 `backdrop-filter: blur(10px)`，搭配細緻的霓虹發光邊框，展現現代網頁的高級質感。
3.  **字體選用**：
    *   **英文與數字**：使用 Google Fonts 的 [Outfit](https://fonts.google.com/specimen/Outfit)，展現幾何、潮流且洗練的現代感。
    *   **中文文字**：使用 [Noto Sans TC](https://fonts.google.com/specimen/Noto+Sans+TC)，確保在不同作業系統下皆能呈現清晰且粗細均勻的閱讀體驗。

## 二、 網頁單元與版面結構 (仿獎金獵人風格)

網站採用雙欄響應式佈局 (Responsive Double-Column Layout)，區分為頂部 Banner 區、左側詳細內容區、右側懸浮側邊欄，以及手機版底部快捷條：

### 1. 頂部 Banner 與簡介區 (Hero Header)
*   **大 Banner**：採用橫幅比例呈現潮流角色主視覺插圖。
*   **標題與狀態資訊**：顯示大字體競賽名稱、主辦單位、狀態標籤（徵件中、角色設計類別），以及動態瀏覽人次、關注人數。

### 2. 左側：主要內容區 (70% 寬度)
*   **橫向 Sticky Tab 導覽列**：固定於頂部，支援 `ScrollSpy` 滾動監聽，在滾動時會自動點亮對應單元：
    1.  **大賽簡介**：企劃背景、動機與目的、現有痛點與解決方案。
    2.  **五大設計人格**：以 Grid 佈局呈現「格哥」、「彩洸」、「像點」、「尺原」、「稿夜」卡片，支援點擊 3D 翻轉展示角色設定細節。
    3.  **參賽辦法**：參賽資格（大專組/高中職組）、報名方式（2-3人組隊，每隊上限5組系列投稿）、作品規格（A3尺寸、 Illustrator .ai 原始檔、300dpi 影像檔、無 AI 參與之原創擔保）與三大評分權重（創意 40%、主題 30%、美感 30%）。
    4.  **大賽時程**：直式發光時間軸，自動根據當前系統時間高亮點亮當前階段。
    5.  **大賽獎項**：金、銀、銅、人氣獎與佳作的獎金卡片展示（總獎金 NT$ 330,000）。
    6.  **注意事項**：智慧財產權歸屬、申報扣稅規定，及得獎者需開立「臺灣中小企業銀行 Hokii 數位存款帳戶」以發放獎金之提醒。
    7.  **互動與報名區**：整合「資格與獎金試算器」、「人氣投票打氣區」與「模擬線上報名表單」。

### 3. 右側：懸浮側邊欄 (30% 寬度 - Sticky Sidebar)
*   隨著視窗滾動保持懸浮，提供高強度行動呼籲：
    *   **倒數計時器**：精確顯示距離 2027 年 10 月 30 日 23:59 截止剩餘的「天、時、分、秒」。
    *   **快速摘要卡片**：列出首獎 `NT$ 100,000`、主辦信箱與投稿限制。
    *   **馬上報名/打氣按鈕**：引導點擊直接定位至對應區塊。
    *   **分享小工具**：支援模擬分享至 Facebook、Line 與複製連結。

### 4. 手機版底部固定快捷條 (Mobile Sticky Bottom Bar)
*   在寬度小於 `992px` 時啟用，固定於畫面最底部。左側顯示「距離截止剩餘天數與時分秒」，右側提供「馬上報名」按鈕，最佳化行動裝置的報名轉化率。

## 三、 系統架構與程式碼設計

本專案採無框架 (Vanilla) 前端架構開發，以達到最佳的網頁載入速度與極致的 CSS 動畫效能：

1.  **[index.html](file:///d:/我的程式/IP角色創作競賽/index.html)**：使用 HTML5 語義化標籤（`header`, `main`, `aside`, `section`, `footer`），配置完整的資訊結構，並引入 Google Fonts 與 Lucide 圖標庫。
2.  **[styles.css](file:///d:/我的程式/IP角色創作競賽/styles.css)**：
    *   定義全域 CSS Variables 控制色調與字體。
    *   使用 `display: grid` 與 `position: sticky` 實作雙欄懸浮佈局與滾動導覽。
    *   利用 `transform: rotateY(180deg)`、`perspective` 及 `preserve-3d` 實作流暢的卡片 3D 翻轉。
    *   使用 Media Queries 針對行動裝置 (Mobile) 及平板 (Tablet) 進行 RWD 響應式佈局重構。
3.  **[app.js](file:///d:/我的程式/IP角色創作競賽/app.js)**：
    *   **計時器邏輯**：每秒計算時間差，並即時渲染至桌面端與手機端。
    *   **ScrollSpy 監聽**：透過監聽 `window.scrollY` 動態比對各 `section` 的 `offsetTop`，並實作滾動時的位移補償（避開 Sticky Header）。
    *   **資格試算邏輯**：防呆檢驗組隊人數（2~3人）與投稿數（1~5組），並計算回報最大首獎金額。
    *   **模擬投票邏輯**：點擊打氣時限制單次投票（存入 `localStorage`），並重新計算所有人格的百分比，動態更新進度條 `width`。
    *   **表單驗證邏輯**：提交時對所有必填欄位、手機正則表達式、Email 格式、檔案選取及勾選框進行防呆檢查。

## 四、 驗證與測試計畫

為確保網站的可用性與品質，網站之驗證重點如下：

1.  **跨平台響應式測試**：
    *   在 Desktop (1200px+) 驗證雙欄排版與 Sticky 側邊欄定位。
    *   在 Mobile (小於 600px) 驗證雙欄降為單欄、Tabs 橫向滑動與底部常駐快捷條的顯示。
2.  **互動邏輯防呆測試**：
    *   驗證倒數計時器在每秒更新時，時間單位是否補零，以及截止後是否顯示「徵件截止」。
    *   測試試算器輸入無效人數（例如 1 人或 4 人）時是否會跳出不合規警示。
    *   測試投票打氣成功後按鈕是否正確變為「已為他打氣」，且無法重複投票。
    *   測試模擬報名表單在未填寫時點擊送出，是否能精確在各漏填欄位下方顯示粉紅色錯誤提示。
